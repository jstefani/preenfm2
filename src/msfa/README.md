# msfa : DX7 synthesis engine

Port of the "Music Synthesizer for Android" (msfa) engine as used by
Dexed (https://github.com/asb2m10/dexed, Source/msfa, tag v0.9.4).
Copyright 2012-2013 Google Inc., 2016-2017 Pascal Gauthier.
Apache License 2.0 (see LICENSE-msfa).

Adaptations for the preenfm2:

- Everything lives in namespace `msfa` and files carry a `msfa_` prefix,
  because the preenfm2 already has `Env`, `Lfo` and `Synth.h` and the
  build directory is flat (and macOS filesystems are case-insensitive).
- Block size is 32 samples (LG_N = 5) to match the preenfm2 audio block.
- The sine and exp2 lookup tables are precomputed constants in flash
  (msfa_*_table.inc, generated by replicating the original init code)
  instead of being computed into RAM at boot. The frequency table still
  lives in RAM because it depends on the sample rate.
- Controllers is reduced to what the preenfm2 drives (pitch bend, mod
  wheel); the JUCE/Android plumbing, NEON paths and Tanh table are gone.
- FmCore has no virtual methods (-fno-rtti build) and uses static buffers.
